# Picture Bridge

Picture Bridge is an image profile conversion
tool developed by LimeT.

## Information

- Name: Picture Bridge
- Version: 1.0
- Developer: LimeT

## Features

- Image profile conversion
- Multilingual user interface
- Support for compatible image profile formats

## Supported Languages

- Korean
- English
- Japanese
- Simplified Chinese

## Installation

Download the latest version from the
Releases section.

## Usage

1. Launch Picture Bridge.
2. Select a supported input file.
3. Choose the desired output format.
4. Convert and save the result.
